Конференц.рф
Регистрируемся на странице регистрации, создаем заявки

Стек — Node.js, Express, SQLite, EJS, Bootstrap.

Установка — npm install.
Запуск — node server.js → http://localhost:2281

Роли:
Пользователь может войти и зарегистрироватся, на странице помещений может посмотреть какие помещения есть, после регистрации может создать заявку (выбрать дату, способ оплаты и тд), после завершения мероприятия может оставить на него отзыв.
Админ может просматривать все помещения и заявки, назначать мероприятия или завершать заявки в панели админа (менять статус мероприятий).
